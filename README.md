# 肥翼龍單車狂奔 (Chubby Dino Bike Rush)

Canvas-based endless runner game — dodge obstacles, collect stars, avoid bombs! 🦖🚴⭐

## 🎮 How to Play

- ⬅️ ➡️ / A D — 閃避方向
- ⬆️ ⬇️ / W S — 加速與減速

| Time | Difficulty |
|------|------------|
| 0-20s | Basic obstacles only |
| 20s+ | 天降星獎賞 ⭐ 與危險炸彈 💣！ |
| 30s+ | 路障開始隨機擺動 |

## 🏆 Scoring

- 存活時間: +10 分/秒
- 行駛距離: +2 分/米
- 收集星星: +100 分/個

## 🚀 Run

Just open `index.html` in any modern browser. No build step, no dependencies.

Works on desktop (keyboard) and mobile (touch buttons).
